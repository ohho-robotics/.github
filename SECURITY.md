# Security

## Reporting a vulnerability

Email [varun@ohho-robotics.com](mailto:varun@ohho-robotics.com). This is the public email on the GitHub organization profile.

Include:

* the repository and path
* what you found
* how to reproduce it
* the impact, if you know it

Please do not open a public GitHub issue for an unfixed vulnerability.

There is no bug-bounty program. This file does not state a compliance certification.

## Scope

The public repositories are [OmniBot](https://github.com/ohho-robotics/ohho-omnibot) and this `.github` repository. You can also report issues in OHHO ROBOTICS LTD proprietary software (OhhO OS, the SDK, the Quest and Android apps, and the console) to the same address.
